Escape game "Try to ESCAPE !"

Un jeux vidéo en 2D vue du dessus. Fait sur c# Windows Forms .Net framework 1.7.2. Le but est de touver tout les indices et de réussir les épreuves, plus on avance dans le jeu plus elles sont compliquées. Si vous perdez, vous recommencez depuis le début !
